Gesture Map

One hand, five controls.

Each landmark relationship — the distance and position between fingertips — is translated into a distinct system-level action. Edit these to match your own mapping.

☝️
Point
Index finger extended, others curled. Fingertip position drives cursor movement.
→ MOVE CURSOR
🤏
Pinch
Thumb and index tip come within a threshold distance of each other.
→ LEFT CLICK
✌️
Two-finger pinch
Thumb meets both index and middle fingertips simultaneously.
→ RIGHT CLICK
✊
Fist hold
All fingertips curled toward the palm and held.
→ DRAG
🖐️
Open palm
All five fingers extended and spread.
→ RELEASE / IDLE
Live Demo

This part actually works.

This runs real hand tracking in your browser (MediaPipe Hands via WebAssembly) — pinch your thumb and index finger together to trigger a click, and move your index fingertip to move the dot. It's a browser stand-in for the desktop tool, which uses PyAutoGUI to move your actual OS cursor.

Get Started

Run the desktop tool.

The full version runs locally, reads your default webcam, and controls your actual system cursor via PyAutoGUI.

# clone and enter the project
git clone https://github.com/your-username/gesture-mouse.git
cd gesture-mouse

# set up environment
python -m venv venv && venv\Scripts\activate
pip install opencv-python mediapipe pyautogui numpy

# run it
python gesture_mouse.py
